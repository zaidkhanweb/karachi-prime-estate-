# Karachi Prime Estate

A modern and responsive real estate website built to showcase property listings and make it easy for visitors to explore properties and send enquiries.

## Features

- Property listings with detailed information
- Property search and filtering
- Dedicated property detail pages
- Buy and rent property browsing
- WhatsApp property enquiries
- Email enquiry option
- Services and areas sections
- FAQ section
- Responsive mobile navigation
- Contact and location information
- Mobile-friendly design

## Built With

- React
- TypeScript
- TanStack Start
- Tailwind CSS
- Vite
